# Learning Gaps — Q/A Cards

Spaced-repetition prompts built from the testing + hands-on exercises.
Keep each card as a **question → answer** pair so you can quiz yourself cold (cover the answer, recall, then reveal).

## How to use

- After each chapter's test/exercise, turn every gap into a card below.
- **Tag the cause** of each miss so you know what to change:
  - `#didnt-know` — genuinely new; read/reread more carefully.
  - `#knew-but-forgot` — needs repetition; review these first.
  - `#misread` — understood it, misread the question; slow down.
- Before starting a **new** chapter, spend ~5 min re-quizzing old cards, prioritizing `#knew-but-forgot`.
- When a card is solid across two separate review sessions, mark it `[mastered]` (or delete it).
- Prefer questions that force *explanation* ("why / when / what breaks if…") over recall of a name.

## Card template

```
### Ch<N> — <short topic>   #didnt-know | #knew-but-forgot | #misread
Q: <question — phrase it so the answer isn't given away>
A: <concise answer; include the one detail you missed and, if useful, a 1-line why>
```
